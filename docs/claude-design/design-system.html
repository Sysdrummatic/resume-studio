One source of truth for the OpenCiVera product surface.

A technical, premium design language built on the "Portal" aesthetic — deep space backgrounds, glass surfaces, indigo & teal accents. Every value resolves from CSS custom properties and re-themes between Night and Day from a single attribute.

Brand Assets

The complete logo system. The mark is a hexagonal "portal" badge — concentric rings around a teal core, with three indigo vertices — paired with the Space Grotesk wordmark. Wordmarks below use currentColor, so they adapt to the active mode.

Clear Space & Usage

Keep clear space equal to the height of the hexagon mark on all sides. Don't recolor the wordmark outside the mode tokens, stretch, rotate, or place the mark on a busy photo without the gradient plate. Minimum mark size: 24px.

Colors

Brand hues are constant across modes. Surfaces, text and borders are tokens that swap between Night and Day — toggle the switch (top-right) to preview both. Always reference the token, never a raw hex.
