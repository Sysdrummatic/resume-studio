Usage Instructions

To export SVG files:

  1. Right-click on any SVG logo above
  2. Select "Inspect" or "Inspect Element"
  3. Find the <svg> tag in the developer tools
  4. Right-click the <svg> element and "Copy" → "Copy element"
  5. Paste into a text editor and save as .svg file

Recommended sizes:

  • Favicon: 16×16, 32×32, 48×48
  • iOS App Icon: 1024×1024
  • Android Adaptive Icon: 512×512
  • PWA Icon: 512×512, 192×192
