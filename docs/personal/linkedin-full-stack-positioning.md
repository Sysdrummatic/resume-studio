# LinkedIn Full-Stack Positioning

This note turns the current OpenCiVera project scope into concise LinkedIn-ready language.

## Strong but honest positioning

- Building a `full-stack` SaaS-style application with `Next.js`, `React`, `TypeScript`, and `Supabase`.
- Designing and maintaining `frontend UI`, `server-side APIs`, and `resume/editor workflows`.
- Implementing `authentication`, `session handling`, `RBAC`, and `Row Level Security (RLS)`.
- Working with `Postgres migrations`, `RPC functions`, and a `YAML-first content/data model`.
- Managing `public publishing flows`, `snapshot-based delivery`, and `rollback/unpublish logic`.
- Supporting `deployment`, `redirect compatibility`, `rate limiting`, `audit logging`, and operational QA.
