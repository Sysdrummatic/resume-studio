# Honest Full-Stack Scope

This note separates the project areas that are clearly evidenced in OpenCiVera from the ones that should not be overstated.

## Real skills supported by the project

- `Next.js App Router`
- `React + TypeScript`
- `API routes / route handlers`
- `Supabase Auth`
- `RBAC`
- `Row Level Security (RLS)`
- `Postgres migrations`
- `YAML / structured content models`
- `Netlify deployment basics`
- `rate limiting`
- `audit logs / operational logging`
- `public route and publication workflows`

## Skills to describe carefully

- `Caching & CDN`
- `Availability & recovery`
- `Cloud & compute`

These areas are present in the project context, but they are not the strongest ownership signals in the repository compared with app, auth, database, and publication logic.

## Skills not worth overstating

- `Load balancing`
- `advanced scaling architecture`
- `deep cloud infrastructure engineering`
- `high-availability / disaster recovery engineering`
- `advanced CDN strategy`
- `full DevOps ownership`
- `production SRE / observability engineering`

## Best concise summary

You can describe your role as:

`Full-stack application developer with strong ownership across frontend, backend APIs, auth, database, security, deployment flows, and publication workflows in a Next.js + Supabase architecture.`

## Polish version

Najuczciwiej opisać ten zakres tak:

`Full-stack application developer z mocnym zakresem odpowiedzialności za frontend, backend API, auth, bazę danych, bezpieczeństwo, deployment flows oraz workflow publikacji w architekturze Next.js + Supabase.`
