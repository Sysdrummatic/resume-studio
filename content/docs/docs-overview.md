## Overview

This section collects the practical guides for OpenCiVera: creating a CV,
preparing versions for different roles, publishing, exporting, and managing
your account.

:::warning
This documentation is still in beta. Some features may be missing or incomplete, and the user interface may change in future releases. We welcome your feedback and suggestions for improvement.
:::

## Start here!

If this is your first visit, start with [Publishing your first CV](/docs/tutorials/publishing-your-first-cv). It takes you from the first-use guide to a private Master Resume, a tailored version, and a public link.

## Tutorials

These tutorials focus on one task at a time. Follow them in order when you are
new to OpenCiVera, or jump directly to the part of the workflow you need.

### Recommended learning path

1. [Build and publish your first CV](/docs/tutorials/publishing-your-first-cv)
2. [Understand the Master Resume](/docs/tutorials/master-resume-basics)
3. [Create a CV version for a specific role](/docs/tutorials/create-cv-version)
4. [Publish and share a CV](/docs/tutorials/publish-and-share-cv)
5. [Add a language version](/docs/tutorials/add-language-version)
6. [Import and export your CV data](/docs/tutorials/import-export-cv-data)
7. [Export PDF and ATS text files](/docs/tutorials/export-pdf-and-ats)
8. [Review changes and roll back a revision](/docs/tutorials/revisions-and-rollback)
9. [Troubleshoot save and publish problems](/docs/tutorials/troubleshooting-save-publish)
10. [Manage your account and privacy](/docs/tutorials/account-and-privacy)

The documentation interface can be switched to Polish from the sidebar. The
tutorial bodies are currently maintained in English and use the labels shown in
the application.
