# Export a published LiveCV to PDF or ATS text

**Goal:** download a checked file ready to send to a recruiter.

**Before you start:** [publish your current LiveCV version](/docs/tutorials/publish-and-share-cv). Export uses the published snapshot, not the current draft.

The export tools use the same selected snapshot that visitors see. A draft
The Experience Base and an unpublished LiveCV version are private, so they
are not available through these actions.

## Export ATS TXT

1. Open **Dashboard** and find a published LiveCV version.
2. Open its settings menu.
3. Choose **ATS (TXT)**.
4. Save the text file and check headings, contact details and bullet points in
   a plain-text editor.

ATS TXT is useful when an application form asks for a plain-text resume. It is
also a quick way to inspect the headings and wording that an automated system
will receive.

## Export PDF

1. Open the settings menu for the same published version.
2. Choose **PDF**.
3. Save the generated file. The Dashboard export uses the LiveCV version's default
   published language.
4. Check page breaks, links, dates and the selected language before sending it.

Normal User accounts should use the published PDF action. Draft PDF preview is
an admin-only feature and is not needed for the regular sharing workflow.

:::warning
If a field is missing, check the LiveCV version selection first. Editing the Experience Base alone does not change an export that was generated from an older
publication.
:::

After correcting the source, save the version and publish it again before
exporting a new file.

## Check the result

- Open the downloaded file and check its language, contact details and content.
- In PDF, check page breaks; in TXT, check headings and lists.
- If you make corrections, republish the version and download a new file.
