# What is a LiveCV?

**A LiveCV is a CV (curriculum vitae) published as a web page under its own public link, built from your private Experience Base in the OpenCiVera CV builder.** You can open it in a browser, share the link with a recruiter, and download the same content as a PDF, YAML or TXT file.

:::info
"CV" here means curriculum vitae. A LiveCV is not a video CV, and it has nothing to do with computer vision or the OpenCV image-processing library.
:::

## How a LiveCV is made

1. You keep your complete career record once, in a private **Experience Base**.
2. For each application you select the summary, experiences, skills and languages that fit it. The selection is saved as a **LiveCV version**.
3. You **publish** the version. OpenCiVera freezes a snapshot of exactly that selection behind a **LiveCV link**.
4. Later edits to the Experience Base do not change a published LiveCV until you publish it again.

## What makes it different from a CV file

| | A CV file (PDF or DOCX) | A LiveCV |
| --- | --- | --- |
| Where it lives | Attached to emails, copied between folders | One public link you control |
| Tailoring | A new file per application | A separate version per application, same source |
| Updating | Re-export and resend | Publish again; the link stays the same |
| Privacy | Everything you wrote is in the file | Only the selected content is public; you can disable the link at any time |

## Related questions

- **Is a LiveCV free?** Yes, OpenCiVera is free.
- **Do I need to know YAML?** No. You edit through a form; YAML is available if you want it. See [CV as code in YAML](/docs/tutorials/cv-as-code-yaml).
- **Can I keep several versions?** Yes. See [one master CV, many versions](/docs/tutorials/one-master-cv-many-versions).
