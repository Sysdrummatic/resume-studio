# Create a LiveCV version for a specific role

**Goal:** prepare a tailored selection and appearance without publishing your data.

**Before you start:** [complete and save your Experience Base](/docs/tutorials/master-resume-basics). Have the target job description ready.

Your Experience Base is the complete career record. A LiveCV version is the shorter
selection you want to send for one role or project. Creating one does not copy
the whole document into public view: it stores which entries should be shown.

## Create the version

1. Open **Dashboard** and select **Create LiveCV**.
2. Give the version a title that you will recognize later, such as
   `Frontend Engineer - Acme`.
3. Select the summary, roles, experience, education, courses, skills, and
   interests that support this application.
4. Choose the appearance with **Template** and **Primary color**.
5. Click **Create LiveCV**.

The new entry appears under **Your LiveCVs** as a private draft. You can preview and
edit it immediately, but there is no public URL until you publish it.

## Review the selection

Open the preview and switch between the available LiveCV languages. Read it as a
recruiter would: does the summary fit the role, are the strongest achievements
near the top, and did you leave out anything that should stay private?

The preview uses the current selection from the Experience Base. A link that is already
public is different: it keeps showing its last immutable snapshot until you
publish the version again.

## Edit or remove a version

Use the version's settings menu to **Edit**, **Publish**, export, or
**Delete** it. The editor's main button depends on the version's state: **Save LiveCV**
for a private version (nothing becomes public), **Update LiveCV** for a published one.
**Update LiveCV** saves your changes and replaces the content under the existing public
link; hover over it to see this hint. Deleting the version removes only that selection; your Experience Base stays intact. If the version is public and you want to keep it for later,
choose **Unpublish** instead of deleting it.

:::tip
Create one version per target direction instead of rewriting the same version
for every application. Clear titles make the Dashboard library much easier to
search.
:::


## Check the result

- The version appears in the dashboard as private.
- Its preview contains only the selected entries and the chosen appearance.
- Contact details and content are correct in each intended language.
