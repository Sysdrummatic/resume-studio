# Czym jest LiveCV?

**LiveCV to CV (curriculum vitae) opublikowane jako strona internetowa pod własnym publicznym linkiem, stworzone z Twojej prywatnej Bazy doświadczeń w kreatorze CV OpenCiVera.** Otwierasz je w przeglądarce, wysyłasz link rekruterowi i pobierasz tę samą treść jako plik PDF, YAML lub TXT.

:::info
„CV” oznacza tutaj curriculum vitae. LiveCV nie jest CV wideo i nie ma nic wspólnego z computer vision ani biblioteką OpenCV do przetwarzania obrazu.
:::

## Jak powstaje LiveCV

1. Całą swoją karierę zapisujesz raz, w prywatnej **Bazie doświadczeń**.
2. Na każdą aplikację wybierasz podsumowanie, doświadczenia, umiejętności i języki, które do niej pasują. Wybór zapisuje się jako **wersja LiveCV**.
3. **Publikujesz** wersję. OpenCiVera zapisuje migawkę dokładnie tego wyboru pod **linkiem do LiveCV**.
4. Późniejsze zmiany w Bazie doświadczeń nie zmieniają opublikowanego LiveCV, dopóki nie opublikujesz go ponownie.

## Czym różni się od pliku z CV

| | Plik CV (PDF lub DOCX) | LiveCV |
| --- | --- | --- |
| Gdzie jest | W załącznikach i folderach | Pod jednym linkiem, który kontrolujesz |
| Dopasowanie | Nowy plik na każdą aplikację | Osobna wersja na aplikację, to samo źródło |
| Aktualizacja | Eksport i ponowna wysyłka | Publikujesz ponownie, link się nie zmienia |
| Prywatność | W pliku jest wszystko, co napisałeś(-aś) | Publiczne jest tylko wybrane; link możesz wyłączyć w każdej chwili |

## Powiązane pytania

- **Czy LiveCV jest bezpłatne?** Tak, OpenCiVera jest bezpłatna.
- **Czy muszę znać YAML?** Nie. Edytujesz w formularzu, a YAML jest dostępny, jeśli go chcesz. Zobacz [CV jako kod w YAML](/docs/tutorials/cv-as-code-yaml).
- **Czy mogę mieć kilka wersji?** Tak. Zobacz [jedno CV, wiele wersji](/docs/tutorials/one-master-cv-many-versions).
- **Jak opublikować?** Zobacz [Publikowanie i udostępnianie LiveCV](/docs/tutorials/publish-and-share-cv).
