# Importuj i eksportuj dane CV

Panel pozwala wyeksportować dane CV jako jeden pakiet YAML i zaimportować
wcześniej utworzony pakiet. Przydaje się to przed większą edycją, zmianą
przeglądarki albo przygotowaniem treści poza edytorem.

## Eksportuj kopię

1. Otwórz **Panel**.
2. W karcie **Główne CV** wybierz **Eksportuj**.
3. Zapisz pobrany plik YAML w prywatnym i trwałym miejscu.

Plik zawiera dane konta, a nie tylko publiczne CV. Traktuj go jak każdą kopię
zawierającą dane osobowe i zawodowe.

## Importuj kopię

1. Otwórz **Panel** i wybierz **Importuj**.
2. Wskaż zaufany plik `.yaml` lub `.yml`.
3. Przeczytaj okno potwierdzenia i zaakceptuj import.
4. Po ponownym załadowaniu strony sprawdź główne CV, wersje językowe i wersje
   CV.

Serwer sprawdza pakiet przed przyjęciem. Import nigdy nie publikuje CV: prywatne
wersje zastępują istniejące prywatne dane, a opublikowane migawki i publiczne
linki pozostają bez zmian. Przejrzyj wynik przed kolejną publikacją.

:::warning
Nie przesyłaj prywatnych danych innej osoby ani niezaufanego pliku YAML. Kopie
przechowuj z szyfrowaniem lub kontrolą dostępu.
:::

Jeżeli przyciski Import lub Export nie są widoczne, transfer danych jest
wyłączony w bieżącym środowisku. Kontynuuj edycję w aplikacji lub skontaktuj się
z administratorem.
