# CV jako kod: Twoje CV w YAML

**CV-as-Code oznacza, że treść CV jest zapisana jako ustrukturyzowany tekst (tu YAML) i oddzielona od tego, jak wygląda.** Te same dane mogą być stroną internetową, plikiem PDF lub zwykłym tekstem, można je archiwizować, wersjonować i przenosić między narzędziami.

## Dlaczego YAML

- **Przenośny:** plik tekstowy, który należy do Ciebie i da się go czytać bez konkretnej aplikacji.
- **Czytelny w zmianach:** zmiany są małe i widoczne, dlatego programiści go lubią.
- **Wielokrotnego użytku:** jedno źródło zasila [publiczne LiveCV](/docs/tutorials/what-is-a-livecv), PDF i tekstowy eksport przyjazny systemom ATS.

## Nie musisz pisać YAML

OpenCiVera to przede wszystkim kreator CV. Wypełniasz zwykły formularz, a YAML powstaje automatycznie. Edytor YAML jest dla osób, które chcą bezpośredniej kontroli: możesz do niego przełączyć się, edytować, a formularz pozostaje zsynchronizowany. Serwer waliduje dokument przed zapisem.

## Co możesz zrobić z danymi

- **Wyeksportować** Bazę doświadczeń jako jeden plik YAML do kopii zapasowej lub ponownego użycia. Zobacz [Import i eksport danych LiveCV](/docs/tutorials/import-export-cv-data).
- **Pobrać** opublikowane LiveCV jako PDF, TXT, ATS YAML lub źródłowy YAML CVasCode. Zobacz [Eksport PDF i plików ATS](/docs/tutorials/export-pdf-and-ats).
- **Zaimportować** z PDF, DOCX, YAML lub TXT, sprawdzając wynik, zanim cokolwiek zostanie dodane.
